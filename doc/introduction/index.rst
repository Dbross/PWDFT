Introduction
============

Welcome to PWDFT
----------------

PWDFT (Plane-Wave Density Functional Theory) is a high-performance, massively parallel computational chemistry code for materials science and electronic structure calculations. It implements state-of-the-art methods within the framework of Density Functional Theory (DFT). For a detailed overview of features and capabilities, see :doc:`what_is_pwdft`.

Citing PWDFT
------------

If you use PWDFT in your research, please cite the following reference:

Bylaska, E. J.; Song, D.; Ilton, E. S.; Bagusetty, A.; Bross, D. H.; Vázquez-Mayagoitia, Á.; Hernandez, R.; Gawande, N. (2024). "NWChem and NWChemEx Plane-Wave Methods." In *Comprehensive Computational Chemistry*, Elsevier, pp. 518–543. https://doi.org/10.1016/B978-0-12-821978-2.00094-5

PWDFT is a research code in active development. We hope you find it useful, but please validate any results for your specific application.
